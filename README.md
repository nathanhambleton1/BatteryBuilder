# UNDERTOW offline

Open `undertow.html` in your browser. Keep the `files/` folder beside it, exactly as in the network edition. Download/extract the whole branch into a local folder; do not download only the HTML file.

Solo survival, practice, campaign, ships, flat/3D rendering and local progress remain. Shared-drive access, online duels, fleet activity collection and shared administration are disabled. No shared-folder permissions are requested. Saves belong to this browser and are separate from the network edition; clearing browser data deletes them. Moving the folder or changing browser may change which saves are available.

The network edition remains on the `simulation` branch.

# UNDERTOW offline

Open `undertow.html` with the `files/` folder beside it. Download and extract the whole branch to a local folder.

Normal mode, practice, achievements and campaign are available without a callsign. Every submarine and every campaign mission is unlocked immediately. No player levels, leaderboards, admin controls, online duels or fleet activity collection are shown. The top-right indicator reads OFFLINE VERSION.

Browser-local progress and preferences may be retained when storage is available, but no unlock depends on saved progress. Clearing browser data removes those local records. No shared-drive connection or folder permission is needed.

The network edition remains on the `simulation` branch.
